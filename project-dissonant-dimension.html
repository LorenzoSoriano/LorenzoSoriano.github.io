A 2D puzzle-action concept built around shifting between two versions of the same space.

Dissonant Dimension is an academic Game Design and Game Production exercise. The project defines the game first — dimension shifting, momentum, grappling and traversal — then translates those choices into scope, schedule, budget and positioning.

The case study connects spatial problem solving with the constraints required to produce it.

Each level is conceived as two overlapping states of the same space. Shifting dimension changes which platforms, routes and interactive elements are available, so the player solves traversal problems by reading both versions of the environment rather than treating the shift as a simple visual swap.

The same work then tests the concept as a production proposal: an €85,000 exercise budget, an 11-month schedule, target platforms, a €14.99 premium price and an intended audience. These values are planning constraints for the academic exercise, not forecasts for a released product.

SPACE

Two states, one level

The dimension shift rewrites the traversable layout of the same scene. A route blocked in one state can become possible in the other, making spatial comparison the basis of the puzzles.

TRAVERSAL

Movement as problem solving

Jumping, momentum and grappling are designed as tools for reading and crossing the level. Traversal is therefore part of the puzzle instead of a separate layer placed between challenges.

PRODUCTION

From design to scope

The core mechanics are translated into a production plan with schedule, exercise budget, platforms, audience and price positioning, showing how the concept changes once feasibility becomes part of the design discussion.

The project tests whether a strong mechanic can survive contact with production constraints.

Its value is not only the dimension-shift concept, but the passage from player-facing systems to a project that can be scoped, scheduled and communicated.
